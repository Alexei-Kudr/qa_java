# qa_java
QA Java Project

# Финальный проект 5‑го спринта

## Описание задачи

Вам предстоит помочь зоологам, исследующим семейство кошачьих. Учёные используют специальную программу для записи наблюдений — вам необходимо протестировать её часть.

## Основные требования

1. **Подготовка окружения:**
   - привяжите GitHub к тренажёру;
   - в списке репозиториев появится `qa_java` с заготовкой проекта (подробности — в инструкции);
   - соберите Maven‑проект, подключив:
     - Jacoco;
     - Mockito;
     - JUnit.

2. **Архитектурные требования:**
   - класс `Lion` не должен зависеть от класса `Feline`;
   - используйте принцип инъекции зависимостей.

3. **Тестирование:**
   - напишите моки с помощью Mockito (необходимые моки определите самостоятельно);
   - создайте тесты для классов `Feline`, `Cat` и `Lion`;
   - примените параметризацию там, где это уместно — реализуйте параметризованные тесты;
   - для каждой ветки условия напишите отдельный тест;
   - вызовите каждый метод каждого класса в отдельном тесте (чтобы увеличить покрытие).

4. **Покрытие кода:**
   - оцените покрытие с помощью Jacoco;
   - требуемое покрытие — **не менее 100 %** для классов `Feline`, `Cat` и `Lion`.

## Структура работы

Проект состоит из:
- **обязательного задания** (влияет на оценку);
- **дополнительного задания** (не влияет на оценку, но поможет получить больше опыта).
